Zwei-Faktor-AnmeldungZusätzlich zum Passwort ein 6-stelliger Code aus einer Authenticator-App (z. B. Google Authenticator, Microsoft Authenticator, 1Password). Ohne Code gibt die Datenbank dann keine Daten heraus.
  1. Authenticator-App öffnen und den QR-Code scannen.
  2. Den angezeigten 6-stelligen Code unten eingeben.
